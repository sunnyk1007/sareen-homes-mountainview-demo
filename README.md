# Viridian at Braddock - GitHub-ready website demo

This is a static, GitHub-ready luxury real estate website demo for Viridian at Braddock.

## Files
- `index.html` - website
- `styles.css` - design system and layout
- `app.js` - interactivity
- `site-data.js` - easiest place to edit copy, contact info, lot status, and image paths
- `assets/viridian-at-braddock-brochure.pdf` - placeholder brochure PDF
- `assets/brochure-qr.png` - placeholder brochure QR
- `.nojekyll` - for GitHub Pages

## Fastest edits later
Open `site-data.js` and update:
- community copy
- contact information
- lot statuses
- homesite notes
- brochure path
- media paths

## GitHub Pages
1. Upload the contents of this folder to the repo root.
2. Go to Settings > Pages.
3. Set source to `Deploy from a branch`.
4. Set branch to `main` and folder to `/(root)`.
5. Save and wait for the site to publish.

## Lead capture
This package keeps the same lightweight integration style as the earlier demos.
Paste your Google Apps Script `/exec` URL into `site-data.js` if you want the form to post into Google Sheets.
